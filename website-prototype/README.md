# 学习平台前端

`website-prototype` 是本项目的前端根目录。当前采用原生 HTML、CSS、JavaScript，展示视觉原型，不包含后台、真实 AI 服务或持久化数据。暂不引入框架，待页面设计确认后再确定技术选型。

## 目录

```text
website-prototype/
  index.html          页面入口
  src/
    main.js           页面内容、导航及原型交互
    learning-ui.js    课程、任务及状态预览
    styles.css        页面样式与响应式布局
  scripts/
    serve.mjs         本地开发与构建预览服务
    build.mjs         生成静态构建输出
  docs/
    DESIGN.md         现有视觉决策记录，后续可修订
  dist/               自动生成的构建输出，不直接编辑
  .preview/           本地截图与检查材料，不提交
  .openai/            已有站点标识与托管配置，保留供后续使用
  package.json        前端项目描述与开发命令
```

设计方案和周报材料位于上一级项目目录，不属于前端发布内容。

## 本地查看

需要 Node.js 20 或更新版本，目前没有第三方依赖，无需安装依赖。

```sh
npm run dev
```

默认地址为 `http://127.0.0.1:4173/`。修改后刷新浏览器即可。端口被占用时，可设置 `PORT` 环境变量指定其他端口。

也可以直接打开根目录的 `index.html` 查看当前静态原型。

## 构建与预览

```sh
npm run build
npm run preview
```

构建复制入口和 `src` 到 `dist`。开发服务与预览服务使用相同的默认端口，不能同时占用该端口。网站发布仅使用 `dist` 内容。

## 当前约定

- 页面开发在 `src` 中进行，`dist` 只用作输出。
- 当前页面以 hash 导航切换，不依赖后端路由。
- 原型中的课程、作业、成绩和学情均为示例。
- 本次目录规范化保留既有布局，不代表首页设计已确认。
- 新增图片、图标等静态资源时放入 `src/assets/`，按实际需要创建。
