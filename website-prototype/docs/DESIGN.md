# 学习平台视觉原型

## 产品方向
面向多课程的一站式实践学习平台。学生以个人学习空间为入口，首页优先帮助恢复当前任务，并提供多课程总览、跨课程待办和教师反馈；《Web 前端开发技术》是当前重点展示的课程与在线实验室样例。教师以作业和待批阅内容为入口。使用样例数据展示布局，不接入真实学习、运行、提交或 AI 服务。

## 视觉选择
浅色左侧导航，中性浅灰工作区，白色课程与反馈表面。首页使用浅蓝背景区分当前任务，实心蓝按钮强调主要操作，文字链接和描边按钮承载次级入口。实验室使用深色代码区和白色预览区，形成开发环境的识别感。无营销式大幅头图，无装饰照片。

## 基础规则
- 字体：系统字体与 Microsoft YaHei 回退，代码使用 Consolas。
- 主正文 16px，常用标签 14px，辅助元信息 12–13px；中文正文行高 1.65。
- 页面标题 28px，区块标题 18–20px。内容尽量使用列表、细分隔线和自然分栏。
- 画布 #f7f7f5，表面 #fff，文字 #262c36，次文字 #606873，边框 #e0e3e7，主操作 #315cc8，链接 #2e539e。
- 当前任务背景 #e5edfb，任务辅助文字 #4d5c73，分隔线 #b9cbea；导航使用白色表面与细分隔线。圆角：按钮 7px，内容区域 12px。仅浮层使用明显阴影。
- 导航固定宽度 220px，页面边距 32px，内容区域适度留白。任务主操作置于任务本身。
- 状态同时用文字表示；蓝色用于操作、选中、学习进度与信息提示，绿色 #247052 用于完成，橙色 #97520c 用于逾期/关注，红色 #a93434 用于错误。教师新反馈使用文档图标和信息蓝色。
- 原型全局注明示例数据；按钮只展示页面切换或原型说明，不制造保存与提交成功。

## 响应式和行为
桌面展示稳定侧栏与多列布局。窄屏侧栏收为紧凑导航，首页依次呈现当前任务、其他待办与反馈、课程总览。实验室小屏通过页签切换任务、代码和预览，避免挤压文字。键盘焦点清晰，减少动态效果，不依赖动画理解内容。

## 页面范围
学生学习工作台、课程章节、在线实验室、学习记录、教师工作台。页面切换用于检查视觉，所有课程、成绩和学情均为示例。

## 入口、状态与可访问性
- 手机导航使用“学习首页 / 我的课程 / 作业任务 / 更多”。更多展开后提供学习记录、消息、帮助与教学入口；Escape、离开导航焦点或点击外部时收起。顶部保留“学习空间”名称。
- 加入课程使用原生 dialog，包含标签、必填/无效/重复邀请码提示；焦点保留在对话框内，关闭后回到入口。示例邀请码对应 WEB2026、DB2026、UX2026、NET2026；仅在本次页面预览中加入，刷新后恢复，不模拟后台保存。
- 键盘焦点使用深蓝轮廓，反馈链接内侧显示完整轮廓；深色编辑器页签使用浅蓝内侧轮廓。提供跳到主要内容入口；路由切换后焦点移至新页面标题。当前配色的实测对比度见下方记录。
- 无课程、无待办与加载失败分别呈现明确说明和下一步；失败时不将未知课程数量显示为零。使用帮助提供状态预览，?scenario=empty、clear、error 为显式示例场景，默认无真实网络请求；重新加载恢复默认示例。
- 已检查 1440px、2048px、720px、390px、320px：首页无横向溢出，课程/作业去向、资料展开、加入课程、过滤空状态、重试、更多导航及键盘流程通过。截图 .preview/review-fixed-*.png，构建通过。
