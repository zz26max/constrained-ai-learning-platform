# 学习平台视觉原型

## 产品方向
面向多课程的一站式实践学习平台。学生以个人学习空间为入口，课程集合是首页主体，继续学习、跨课程待办和消息通知提供快速回到具体任务的路径；《Web 前端开发技术》是当前重点展示的课程与在线实验室样例。教师以作业和待批阅内容为入口。使用样例数据展示布局，不接入真实学习、运行、提交或 AI 服务。

## 视觉选择
深墨蓝左侧导航，浅冷灰工作区，白色内容表面，以清晰的蓝色强调操作。实验室使用深色代码区和白色预览区，形成开发环境的识别感。无营销式大幅头图，无装饰照片。

## 基础规则
- 字体：系统字体与 Microsoft YaHei 回退，代码使用 Consolas。
- 主正文 16px，常用标签 14px，辅助元信息 12–13px；中文正文行高 1.65。
- 页面标题 28px，区块标题 18–20px。内容尽量使用列表、细分隔线和自然分栏。
- 画布 #f3f6fa，表面 #fff，文字 #192b42，次文字 #62718a，边框 #e2e8f0，操作 #285ce6。
- 深色导航 #111f35。圆角：按钮 7px，内容区域 12px。仅浮层使用明显阴影。
- 导航固定宽度 220px，页面边距 32px，内容区域适度留白。任务主操作置于任务本身。
- 状态同时用文字表示，蓝色是操作与选中，绿色用于完成，橙色用于需要关注。
- 原型全局注明示例数据；按钮只展示页面切换或原型说明，不制造保存与提交成功。

## 响应式和行为
桌面展示稳定侧栏与多列布局。窄屏侧栏收为紧凑导航，内容顺序排列。实验室小屏通过页签切换任务、代码和预览，避免挤压文字。键盘焦点清晰，减少动态效果，不依赖动画理解内容。

## 页面范围
学生学习工作台、课程章节、在线实验室、学习记录、教师工作台。页面切换用于检查视觉，所有课程、成绩和学情均为示例。

## 首页层级（方向 B：紧凑课程网格，2026-10-01）
首页以“我的学习”和学期信息开头，待办与新反馈为轻量文字摘要。主体采用两列课程单元：课程名称最突出，班级/教师与当前章节为辅助信息，下一项任务与操作紧邻。最近学习的 Web 课程使用浅蓝任务区域和主按钮，教师反馈在同一课程底部；只有课程入口的 UX 单元按实际内容自然缩短，不补齐虚构任务。最近通知独立于课程，在网格剩余位置轻量呈现。

保留 icon、button、text-link、tag、progress-track 及全局颜色和圆角变量。进度以紧凑短条呈现，明确区分实验与章节口径。移除原首页横向流程箭头及手机纵向节点。主体最大宽度 1440px，常规边距 40px，网格间距 24px。标题 28px、课程标题 22px、任务名称 17px、章节 14px、辅助信息 12–13px。

1000px 以下单列，650px 以下收紧留白，主要操作至少 44px 高；320px 时任务操作自然换行。延续侧栏、键盘焦点与减少动效设置，不使用固定卡片高度。课程入口按课程标识分别进入章节页，课程目录与作业任务共用示例数据。首屏按截止时间指出优先任务，文字说明逾期状态；状态计算使用明确标注的示例日期 2026-10-01，保留原任务日期。UX 已完成部分章节，状态统一为学习中。

## 入口、状态与可访问性
- 手机导航使用“学习首页 / 我的课程 / 作业任务 / 更多”。更多展开后提供学习记录、消息、帮助与教学入口；Escape、离开导航焦点或点击外部时收起。顶部保留“学习空间”名称。
- 加入课程使用原生 dialog，包含标签、必填/无效/重复邀请码提示；焦点保留在对话框内，关闭后回到入口。示例邀请码对应 WEB2026、DB2026、UX2026、NET2026；仅在本次页面预览中加入，刷新后恢复，不模拟后台保存。
- 加深浅蓝任务区文字至 #52647b，测得对比度约 5.41:1。键盘焦点使用深蓝轮廓，反馈链接内侧显示完整轮廓。新增跳到主要内容入口；路由切换后焦点移至新页面标题。
- 无课程、无待办与加载失败分别呈现明确说明和下一步；失败时不将未知课程数量显示为零。使用帮助提供状态预览，?scenario=empty、clear、error 为显式示例场景，默认无真实网络请求；重新加载恢复默认示例。
