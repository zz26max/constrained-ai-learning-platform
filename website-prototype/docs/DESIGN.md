# 学习平台视觉原型

## 产品方向
面向多课程的一站式实践学习平台。学生以个人学习空间为入口，课程集合是首页主体，继续学习、跨课程待办和消息通知提供快速回到具体任务的路径；《Web 前端开发技术》是当前重点展示的课程与在线实验室样例。教师以作业和待批阅内容为入口。使用样例数据展示布局，不接入真实学习、运行、提交或 AI 服务。

## 视觉选择
浅色左侧导航，浅冷灰工作区，白色内容表面，以清晰的蓝色强调操作。首页将深墨蓝集中用于当前学习任务，实验室使用深色代码区和白色预览区，形成开发环境的识别感。无营销式大幅头图，无装饰照片。

## 基础规则
- 字体：系统字体与 Microsoft YaHei 回退，代码使用 Consolas。
- 主正文 16px，常用标签 14px，辅助元信息 12–13px；中文正文行高 1.65。
- 页面标题 28px，区块标题 18–20px。内容尽量使用列表、细分隔线和自然分栏。
- 画布 #f3f6fa，表面 #fff，文字 #192b42，次文字 #62718a，边框 #e2e8f0，操作 #285ce6。
- 当前任务背景 #111f35，导航使用白色表面与细分隔线。圆角：按钮 7px，内容区域 12px。仅浮层使用明显阴影。
- 导航固定宽度 220px，页面边距 32px，内容区域适度留白。任务主操作置于任务本身。
- 状态同时用文字表示，蓝色是操作与选中，绿色用于完成，橙色用于需要关注。
- 原型全局注明示例数据；按钮只展示页面切换或原型说明，不制造保存与提交成功。

## 响应式和行为
桌面展示稳定侧栏与多列布局。窄屏侧栏收为紧凑导航，首页依次呈现当前任务、其他待办与反馈、课程总览。实验室小屏通过页签切换任务、代码和预览，避免挤压文字。键盘焦点清晰，减少动态效果，不依赖动画理解内容。

## 页面范围
学生学习工作台、课程章节、在线实验室、学习记录、教师工作台。页面切换用于检查视觉，所有课程、成绩和学情均为示例。
