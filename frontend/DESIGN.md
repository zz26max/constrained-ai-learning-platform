# 知学学生工作台

本目录的界面实现记录；业务、接口和正式前端约定仍以仓库 docs 为准。

## 产品与信息顺序

服务正在完成课程任务的学生。沿用白灰画布、蓝色操作、固定侧栏和真实教学数据。首页先回答下一步操作，再展示近期待办、最近两门学习课程、反馈与公告，最后展示概览数字。列表页优先扫描效率，不把每条记录放进独立大卡片。

## 组件与视觉

- 复用 zhixue.css 的 ink/muted/line/blue/blue-soft；状态使用蓝色进行中、绿色已批改、橙色临近截止/补交，始终附带文字。样式由 student-workbench.css 增量覆盖。
- 页面标题24–26px，核心任务22px，列表正文14px，辅助信息12–14px。中文系统字体回退不变。
- 容器间20–24px，列表内部12–20px；按钮至少44px高。蓝色实心用于当前核心任务；其他列表操作使用描边。
- TaskStatus 分开呈现处理状态与时间状态。taskAction 只在真实详情 canSubmit=true 时显示开始/继续/补交；列表未确认资格或读取失败时使用查看详情。
- 待完成视图排除归档历史，全部视图保留。课程、作业筛选与排序基于完整分页数据，失败不能显示成功空态。课程按 lastStudiedAt 排序；不解析或改写业务标题里的测试编号。

## 窄屏

760px以下使用单列任务和底部首页/作业/课程/消息/更多入口；更多仍使用现有侧栏，支持Esc关闭。内容底部保留导航空间。筛选项可在区域内横向滚动，页面本身不横向滚动。作业列表改为纵向信息行，保留课程、截止、状态与操作。

日历保留既有月/周、两项溢出入口和手机日期条；手机日期按钮去除挤压文字的水平内边距。没有课表接口，不创建普通学习事件。

## 验证边界

使用现有49项作业、数十条消息和多课程数据复核，截图不替换成整齐样例。自动检查不能替代真实学生的“3秒任务测试”；数据清理、损坏原文恢复与学生可用性实验须单独处理。截图与检查结论见STATUS记录。

## B+ 候选：B的焦点与A的连续排版

- 默认原首页不采用B+；探索控件仅在design参数的预览页面出现。B+提供收起的方案入口，避免占据手机首屏。
- 深蓝任务区保留，只呈现任务名称、课程、处理状态、单一截止信息及主操作。桌面截止信息置右，手机置于操作之前；当前年/分钟按阅读需要简化，完整时刻仍在机器可读time/提示中。业务canSubmit判断未改。
- 近期任务按精确截止时刻分组，等价时区归同组；每组仅一次日期/时间和剩余时间。不同任务仍有独立链接，不合并作业对象。列表采用A的分隔线，去掉B的外框与白底。
- 桌面左栏任务与右栏课程/反馈独立流动，避免课程高度撑大主任务后的空白；手机按核心任务、近期任务、最近课程、反馈/公告、概览顺序堆叠。
- 最近课程仅一门，用已有章节接口读取已开放章节的真实阅读状态；保留小mark、课程状态、进度与最近章节。全部已开放章节读完仅表示可以复习，不表示课程已结课；无章节或进度未知不虚构下一章。
- 课程、反馈与公告去掉独立背景和外框，以细分隔线组织；反馈分数26px中性色，只标本次评价。公告标题和未读标记同行优先。概览保持低权重文字行。
- 主标题25–31px、任务标题25–29px、任务正文15px、主要操作14px、辅助信息13px；少量日期分组说明12px。保留现有字体、品牌蓝、深蓝，无新依赖或装饰动效。

## V3.4 视觉探索：学习的形状（方向获认可，尚未替换正式页面）

仅在独立高校预览 `campus.html?explore=v34` 中启用，不覆盖上述正式规则。目标为现代学术感、可辨识的学习过程与编辑式节奏；范围只有课程、记录、日历。记录先完成桌面/手机渲染审阅，再推广另外两页。

- **课程索引**：学科图形、章节路径与日历任务沿用同一套细线几何和学科色。按已知 mark 显式分组：JAVA/WEB 程序与交互（#2853bc / #eef2ff）、DB/DSA 数据与结构（#1b6b65 / #eaf5f1）、NET/SE 系统与工程（#5a527e / #f0eef7）、AI/MEDIA 探索与表达（#805e1e / #faf3e4）；未知 mark 使用中性灰，不从标题猜学科。颜色表示学科，阅读状态仍用文字、序号与节点形状表达。
- **课程构图**：桌面为学科书脊加内容区，不是整张彩色封面；手机重组为小图形与标题并列，进度/位置/动作连续排列。计数分段仅表示阅读数量、不代表具体章节顺序；只有记录页才展示章节的实际状态。无开放章节显示“尚未开放”，不画假进度或0/0完成率。
- **学习路径**：序号方节点、连线、已读实心、阅读中描边与侧线、未读中性边界；每章保留完整标题和44px阅读动作。桌面路径与成果共用整个工作区，单章节采用平衡分栏，超过8章收紧节点间距；1100px下辅助成果改到路径之后，600px下单列。无章节是说明性空态，不虚构未来节点。
- **学习成果**：仅使用阅读数量、Web实验数量、已发布评价和本次反馈分数。首页式统计卡片不放在顶部；教师评价在桌面与路径并列，在手机位于路径后。不新增学习时长、连续天数、掌握率或能力评分。
- **时间分布**：月格按真实截止数呈现0/1/2/3+层级并附图例、显式数量；学科细线替代重复橙色标签。右侧按截止时刻组织日程。手机保留周日期条，以数量文字补充背景深浅；不缩小桌面七列月历。日历只表截止与已有处理状态，不凭日期推断提交资格。
- **基础**：主文字#192c4d、辅助#53647b、分隔#d9e1ed、白色纸面；沿用中文系统字体。标题26–28px、区块18–21px、正文14–16px、辅助12–13px；月格摘要12px。控件至少44px高，图形线宽1.8、节点与控件6–8px圆角、版块10px；仅轻底色与边界，不引入图片、字体、动画或依赖。
- **比较与隔离**：版本参数仅为呈现开关；切换保留内存业务状态、记录所选课程、日历日期/视图/筛选和课程筛选。未探索页面保持原组件。数据适配器、固定时钟与网络隔离复用V3.3。预览查询/写逻辑以现有页面为来源，冻结在预览目录；正式采纳前应统一维护，不能长期当作第二套业务规则。

视觉改善是设计判断，操作效率需真实学生确认，不根据截图或脚本耗时宣称提升百分比。实际截图、局部图与验证见 V3.4 交付报告；未经确认不推广到其他页面。

- **构图**：首页A保留任务与右栏并置，日期建立独立索引；近期任务使用日期侧栏而非重复段落标题。首页B曾尝试全宽焦点后再分栏，因推迟辅助信息未采用。作业将课程移入标题单元，日期置前，状态/动作各成列；手机独立重组。消息采用日期批次的阅读纸面，保留连续消息行，未读为轻底与侧线，不逐条增加卡片。
- **文字**：中文使用Microsoft YaHei UI、PingFang SC、Microsoft YaHei、系统sans回退；不加载网络字体。标题30/手机27px，焦点29/手机24px，任务16/手机15px，通知17/手机16px，正文14px，操作及主要辅助13px，日期/标识12px。数字日期/分数使用Georgia/Times serif，其他数字tabular-nums；不替换中文正文。字号只按职责调整。
- **时间**：月、日、时刻独立排版，保留北京时间。当前年可省略可见年份，但time datetime与aria-label始终含完整日期；跨年显示年份。大号日数字不能压断时刻；相对截止状态与真实资格独立。不把日期改成权限判断。
- **色彩与表面**：沿用学科色、品牌蓝。主文字#1c2d49、辅助#52627a、分隔#d7dfe9；纸面白、工具栏#e9eef5、反馈#edf2f8、选中/未读#f3f6fd。首页焦点使用#1b3266至#25498d的轻微深蓝层次，边界表达主任务焦点；课程/任务整体纸面仅轻阴影，不嵌套多层同质容器。保留页面冷灰底以衔接未重设计三页。
- **状态与操作**：CraftTaskState保持原枚举、截止状态和canSubmit语义；进度文字配小点，资格用独立文字，补交暖色，未知不可假定成功。日期列承载截止状态，避免重复字段标签。首个任务操作强调，其余轻底描边；消息主操作描边、标读为次级文字，44px点击区域不变。
- **图形和交互**：继续复用SubjectGlyph与五类消息线性图形，图标尺寸18–22px/容器28–38px，固定线宽；不混入装饰图片。Hover/focus/active/disabled明确，颜色与边界过渡140ms，无位移或入场动画，reduced-motion关闭过渡。
- **响应式与密度**：1100px下首页主栏与辅助区重排，清除旧命名grid-area；760px下任务→近期任务→课程→反馈→公告，辅助区完整单列。320px仍保持主要标签13px、通知标题16px、摘要14px。窄屏优先让内容换行，日期与操作采用自己的紧凑关系；不可用缩小字体或隐藏状态压低行高。

上述来自实际A/B局部渲染比较；最终视觉品质与三秒任务定位仍待用户/真实学生评审。截图和验证边界见V3.6交付报告，不将主观取舍包装成评分。


### 正式学生端采用基线（2026-10-20）

正式首页/作业/消息采用V3.6.1固定呈现，未读默认A；课程/学习记录/学生日历采用V3.5精修。上文候选章节保留探索依据，正式入口不提供设计切换。学科、日期、章节分段、任务三维状态和消息图形统一位于features/student/visual；历史候选通过显式包装保留版本语义。

- 首页按现有真实提交资格与截止时间规则展示；补交明确“已逾期，可补交”，展示依据置于主操作后。不得改为自行推断优先级或资格。
- 正式组件只使用真实API和系统时间，不引用demo目录；学科来源是接口mark，未知为中性。课程入口措辞由已发布章节的实际阅读状态决定，不从课程总进度推导当前章节状态。
- 课程筛选与分页为页面局部状态，学习记录保留服务端评价分页和准确ID去重；日历保留北京时间、选择日期与真实详情资格。
- 六页视觉规则仍以页面根类限定；二级页面仅在student-release容器内衔接中文字体、14px正文/1.65行高、28px标题（手机26px）、44px主要控件与3px键盘焦点，不重排编辑器。teacher及隔离预览不获得student-release类。
- 不减少错误、归档或未知状态。普通主次文字仍使用#1c2d49/#52627a，品牌#2853bc；学科色不承载任务紧急度。沿用已定760/1100响应式、无位移动效和reduced-motion规则。


### 正式学生端内容层次精修（2026-10-20）

在既有V3.6.1/V3.5基线上分三级密度：深蓝主任务为唯一最强焦点；日期任务流、作业行、消息流及评价历史使用轻底/描边组织；教师、来源、相对时间等仍用文字与留白，不单独做卡片。

- 共享层为features/student/visual/content.css，仅student-release根生效。纸面/正文/辅助/分隔复用surface、ink、muted、line，内容行与日期批次补少量语义token；无新阴影、渐变或装饰图标。保留旧版预览样式。
- 首页近期任务按北京时间自然日组织，一日一个日期轨道和连续任务区；组只显示月/日，任务保留自己的准确截止时刻与时间状态。不同截止时刻不合并为同一截止时刻；未丢弃或重排候选待办。
- 作业的视觉权重来自原有进度、归档、服务端overdue和确认后的canSubmit。即将截止的强调仅作用于24小时内且确实可提交的待办，不制造优先级或权限。日期列与操作列有边界，移动端按标题/课程/日期/状态与动作组织；320px允许动作独占一行以避免挤压状态。
- 消息保留类型图形、未读文字/点/侧线；未读背景改为极浅fafbfe，标题700，已读600且保持正文对比。桌面时间和动作同在末尾，手机在摘要后展示时间和操作；长内容仍按真实溢出展开，不为了整齐新增展开入口。
- 课程进度与元信息间增加轻分隔，学习记录只将评价历史成组，保留已成熟章节路径。新增路径分隔线经截图评审撤回，避免强化概况与路径割裂。日历通过选中边界、课程侧线和日程整体容器关联日期与任务，不为无任务日期增加装饰。
- Hover和focus-within反馈落在连续行内部，不增加上浮/位移。沿用44px主要触控、键盘focus-visible、disabled与reduced-motion规则；小间距6px、信息组14px，页面模块间距沿用原值，不整体放大密度。
