# 知学学生工作台

本目录的界面实现记录；业务、接口和正式前端约定仍以仓库 docs 为准。

## 产品与信息顺序

服务正在完成课程任务的学生。沿用白灰画布、蓝色操作、固定侧栏和真实教学数据。首页先回答下一步操作，再展示近期待办、最近两门学习课程、反馈与公告，最后展示概览数字。列表页优先扫描效率，不把每条记录放进独立大卡片。

## 组件与视觉

- 复用 zhixue.css 的 ink/muted/line/blue/blue-soft；状态使用蓝色进行中、绿色已批改、橙色临近截止/补交，始终附带文字。样式由 student-workbench.css 增量覆盖。
- 页面标题24–26px，核心任务22px，列表正文14px，辅助信息12–14px。中文系统字体回退不变。
- 容器间20–24px，列表内部12–20px；按钮至少44px高。蓝色实心用于当前核心任务；其他列表操作使用描边。
- TaskStatus 分开呈现处理状态与时间状态。taskAction 只在真实详情 canSubmit=true 时显示开始/继续/补交；列表未确认资格或读取失败时使用查看详情。
- 待完成视图排除归档历史，全部视图保留。课程、作业筛选与排序基于完整分页数据，失败不能显示成功空态。课程按 lastStudiedAt 排序；不解析或改写业务标题里的测试编号。

## 窄屏

760px以下使用单列任务和底部首页/作业/课程/消息/更多入口；更多仍使用现有侧栏，支持Esc关闭。内容底部保留导航空间。筛选项可在区域内横向滚动，页面本身不横向滚动。作业列表改为纵向信息行，保留课程、截止、状态与操作。

日历保留既有月/周、两项溢出入口和手机日期条；手机日期按钮去除挤压文字的水平内边距。没有课表接口，不创建普通学习事件。

## 验证边界

使用现有49项作业、数十条消息和多课程数据复核，截图不替换成整齐样例。自动检查不能替代真实学生的“3秒任务测试”；数据清理、损坏原文恢复与学生可用性实验须单独处理。截图与检查结论见STATUS记录。
