## 1. 访问与隔离边界

项目根目录运行：

```powershell
npm --prefix frontend run dev:campus
```

打开 [高校演示首页](http://127.0.0.1:4174/campus.html#/student/home)。服务默认仅本机可访问；本次交付时已启动。退出后可刷新重置，或用虚构账号 `campus.student / campus-preview` 登录。正式端的 `student.demo` 与本演示账号无关，未更换现有用户、课程或作业。

检查发现原有 Mock 与自动化边界夹具共享状态，内容不足以用于自然校园演示，因此没有替换或扩充原 Mock。采用独立 HTML、开发配置与内存 Transport，复用现有路由、学生页面、API 客户端和样式；无需新建数据库、迁移、后端接口或复杂数据系统。

| 边界 | 实现与证据 |
| --- | --- |
| 数据 | `src/demo/campus/data.ts` 每次创建独立状态；不同标签页、刷新均重新初始化。没有数据库、localStorage、Cookie 或真实 fetch 写入。 |
| 网络 | 4174 没有后端代理，`/api/` 请求返回 503；未知模拟操作明确报错，不转发真实接口，不返回伪造成功。 |
| 普通开发端 | 4173 的演示 HTML 与入口模块均返回 404；正常主入口不导入演示启动模块。 |
| 生产 | 演示配置拒绝 build；入口检查 DEV、campus 模式、mock 开关；正常构建不含 campus.html、演示账号或标记，生产扫描已覆盖。 |
| 身份 | 自动登录虚构学生，仅 student 角色；不新增教师端实现，不修改权限或契约。 |
| 可识别性 | 所有页面持续显示虚构数据、固定日期、重置入口和操作说明；演示栏样式仅作用于预览包装层。 |

**支持隔离交互**：课程/章节浏览与筛选、恢复阅读位置、确认阅读、文本/SQL/Web 工作区编辑与保存、模拟提交及不可变快照、查看既有演示评价、消息已读、消息展开、日历月周/日期选择/详情跳转、应用内返回。刷新会撤销全部模拟变化；任务中途请勿刷新。

**不支持**：真实数据库持久化、真实教师收件和批改、执行 SQL/评分、AI 辅导、行为分析、加入新教学班或教师操作。未包含的操作会明确失败；它们不能作为正式业务完成证据。章节提供演示导读，不是完整教材或真实课程资源库。

潜在风险：固定时钟替换仅发生在独立页面，影响该页所有 Date 调用，这是为了相对时间可复现；计时器和 performance 不冻结。热更新、刷新、关闭页面可能丢失练习，预览已明示。Vite 是本地开发服务，不应作为正式公开托管服务。
