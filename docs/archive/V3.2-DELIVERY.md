| 区域 | 实际修改及结果 | 保留的原行为 |
| --- | --- | --- |
| 课程 | 顶部蓝描边降为普通1px边框；mark缩为28px高；标题与最近章节保留；进度标签/数字顶行对齐、5px轨道占满信息列；整理此前移动margin与重复覆盖 | 桌面双列/手机单列、真实章节数据、课程详情/章节/非零待办与反馈入口；100%仍为复习 |
| 记录 | 内容分区限宽880px并保持原左起点，长评语限64ch；日期与分数列共用对齐；章节链接至少44px高、节点对齐首行；单章与汇总减少无效留白 | 课程选择、连续路径、状态未知、按ID反馈去重、完整评语、原分页 |
| 消息 | 以真实DOM裁切检测代替字符数猜测；完整可见消息无多余全文；长内容仍完整展开，标题只显示一次；宽度变化时重新测量，展开中保留控件，关闭后控件消失时焦点落回本条标题；日期用间距分组，已读/未读文字对齐 | 五类筛选、独立通知、不合并同标题、状态与目标跳转/标读；展开不标读 |
| 首页 | 保持B+构图；任务标题28px/600，截止数字600与等宽数字；深蓝区浅色焦点；辅助课程链接中性、主学习入口仍强调；所有辅助课程入口至少44px宽/高 | 推荐资格、日期分组、任务对象、最近课程与公告反馈、概览；原版/A/B保留 |
| 作业 | 给既有标签增加纯展示语义类；处理状态保留浅底，时间状态去实色填充，资格用边框/文字；截止数字等宽，组标题减轻重量 | 全量真实资格排序后分页、补交规则、数量、任务原状态与独立按钮均不变 |
| 日历 | 截止事件减轻橙色填充并保留左侧线与截止文字；溢出入口44px高；日期数字层级与详情标题校准；手机日期条允许自然收缩 | 今天轮廓/选中实色、月周/手机周条、每格2事件/溢出项、详情与空日期真实导航 |
| 通用状态 | 学生控件统一字重/内边距、按下/悬停反馈；输入焦点边框明确；仅在no-preference使用120ms颜色/边框过渡，reduce时无过渡 | 不重建控件、不增加位移动画、不影响教师样式 |

修改依据不是继续压缩页面。最终同数据样本：390px首张课程322.97→306.84px；1440px课程293.97→294.97px。进度信息占据清晰的列宽，桌面几乎不增高。首条消息390px为217.52→226.47px（约9px），1440px为170.48→175.28px；少量增加用于标题行高与操作间距，不声称所有消息都变矮。消息的主要收益是完整可见时去掉无效全文入口、未读与已读共用起点、展开不重复。

没有采用随机学科颜色、封面、卡片化、全站大幅缩字或填充无数据统计。共享TaskStatus只增加CSS语义类，视觉变化限制在student-space，教师页面未改。

- styles/student-v3.css：在现有文件内按页面/断点整合旧覆盖，落实课程/记录/消息和控件状态，未增加第二套样式系统。
