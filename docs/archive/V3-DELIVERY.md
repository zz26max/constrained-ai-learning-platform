## 设计与实现

正式采用 B+ 的学术简约与现代学习工作台方向。首页以深蓝任务突出下一步，其他页面用信息自身的结构建立层级。颜色、字体、间距、控件、进度、响应式规则见 DESIGN.md 的 V3 正式规范，实际映射至 src/styles/student-v3.css。沿用系统中文字体、既有品牌与 AppIcon，无新增依赖。

| 页面 | 原问题与实际变化 | 保留的业务入口与交互 |
| --- | --- | --- |
| 首页 | B+仅预览→默认正式首页；手机辅助字增大、链接触控扩大、无学期提示补齐 | 可提交资格、下一任务、精确日期分组、最近课程、复习语义、反馈公告、学期概览；原版/A/B显式参数仍可预览 |
| 我的课程 | 标识/状态/标题接近→mark独立轻量标识，两行标题保留完整title，最近学习与进度分区 | 学期/状态筛选、按最近学习排序、分页、加入课程、章节直达；归档仅查看，100%不表述为结课 |
| 学习记录 | 白色大容器与统计块→无框分区、连续章节节点、行内汇总 | 课程选择、已发布章节排序、阅读/复习入口、最近阅读时间、实验数、反馈、服务端分页；缺失阅读状态明确未知 |
| 我的作业 | 表头与辅助字偏弱→13px表头/辅助信息，15px标题，行悬停/焦点、操作列对齐 | 状态与课程筛选、截止排序、分页、独立操作；手机为纵向条目，已截止不可提交显示查看详情 |
| 学习日历 | 工具栏/日期状态与其他页不协调→分隔式工具栏、今天轮廓、选中实色、轻量右侧日程 | 月/周切换、前后翻页、今天、日期详情、课程筛选、每天两项与溢出入口；手机周日期条 |

课程保留双列与手机单列；作业保留表格；记录采用路径；日历采用日期；消息采用收件箱。减少重复面板主要发生在记录、日程侧栏、消息，而不是为统一重做全部布局。
