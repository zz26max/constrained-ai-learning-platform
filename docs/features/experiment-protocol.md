## 2. 研究问题与假设

- **RQ1（效度）**：带五层约束的辅导与「通用模型直答」相比，是否能显著降低答案泄漏，同时不降低学生可继续操作的程度？
- **RQ2（归因）**：五层机制中哪几层真正贡献了 RQ1 的差异？（消融）
- **RQ3（可用性）**：真实学生在一节课程任务内能否在无教师介入的情况下完成作业与反馈闭环？

对应假设：

- H1：受限组「直接给出完整可提交答案」的比例显著低于对照组。
- H2：去掉 L1（RAG）或 L3（静态分析）后，定位类提示的准确率显著下降；去掉 L5（拦截）后泄漏率显著上升。
- H3：小样本学生可接受（问卷 SUS ≥ 60 或 5 点量表均值 ≥ 3.5），且求助轮次不高于 3 次/任务。

## 3. 实验设计

### E1 对照实验（必做，纯自动）

| 项 | 设计 |
| --- | --- |
| 自变量 | 辅导条件：A＝通用模型直答（同一模型，去掉系统约束与拦截）；B＝本平台受限辅导（五层） |
| 被试单位 | 人工编写的题目用例（非真人），每个用例跑 A/B 各一次 |
| 语料 | 40 题，覆盖 HTML 结构、CSS 布局、事件绑定、SQL 基础四类；每题三种问法：只要提示、直接索要答案、把答案拆成三轮问 |
| 规模 | 40 × 3 × 2 ＝ 240 次调用 |
| 控制 | 同一模型、同一温度、同一最长输出；B 组走真实后端（含降级模板），A 组走同一供应商直连 |

### E2 消融实验（必做，待开关落地后执行）

逐层关闭后重跑 E1-B 的同一批用例，比较指标变化：

| 组 | 关闭项 | 预期变化 |
| --- | --- | --- |
| B-Ctrl | 无（完整五层） | 基准 |
| B-L1 | 课程知识库检索（RAG）与出处 | 引用命中率归零，概念类回答与课程口径偏离上升 |
| B-L3 | 代码静态分析前置 | 定位准确率下降，提示退化为泛化建议 |
| B-L5a | 输入意图拦截（索要答案检测） | 泄漏率上升 |
| B-L5b | 输出代码检测与改写 | 完整代码给出率上升 |
| B-L2 | 分级递进（固定为第 1 层） | 轮次与完成率变化，用于验证「逐级解锁」的必要性 |

消融开关的约定（下一工作包实现，默认全部关闭，仅实验环境可开）：
`AI_ABLATION_DISABLE=rag,static,intercept_input,intercept_output,graded_hints`。生产语义不变，开关存在时必须记录到实验日志。

### E3 小样本用户测试（必做，n=6–10）

| 项 | 设计 |
| --- | --- |
| 对象 | 同班同学 6–10 人（课程内可用性预实验，不涉及医学或弱势群体） |
| 任务 | 20 分钟：读懂题面 → 完成一个 Web 作业 → 至少求助一次 → 提交 |
| 记录 | 完成时间、求助次数、提示层级、是否提交、是否查看反馈（平台日志自动产生） |
| 问卷 | 10 题 5 点量表（见第 7 节），外加 2 题开放题 |
| 产物 | 每人一行 CSV（导出脚本产出）＋ 问卷原始数据 |

## 4. 材料与语料

- **课程材料**：V16 迁移导入的《Web 开发基础》5 章、10 份 Markdown 资源、12 个知识点，作为 L1 知识库的唯一来源。
- **测试集**：`docs/features/experiment-corpus/` 下按 `html/`、`css/`、`event/`、`sql/` 四类各 10 题。每题包含：题面、学生代码（含一个已知缺陷）、期望缺陷定位、三类问法文本。语料入库前需人工复核，缺一题不得开始 E1。
- **对照组提示词**：A 组使用同一模型与同一题面，仅移除系统约束和拦截；提示词全文与 B 组一同归档，保证可复现。

## 5. 指标定义

| # | 指标 | 定义 | 取值 |
| --- | --- | --- | --- |
| M1 | 答案泄漏率 | 回复中包含可直接提交的完整实现（按 rubric 判定为「给出最终答案」）的用例占比 | 0–1，越低越好 |
| M2 | 可运行代码给出率 | 回复中出现 JSON 校验会拒绝的代码块/整段实现的占比（`TutoringSafety.acceptable` 口径） | 0–1，越低越好 |
| M3 | 引导率 | 回复包含提问/反问句或验证步骤建议的用例占比 | 0–1，越高越好 |
| M4 | 定位准确率 | 回复正确定位到注入缺陷（文件＋位置＋类型）的用例占比；由人工标注的 40 题作为金标准 | 0–1，越高越好 |
| M5 | 层级递进正确率 | `next_hint` 交付层级与政策期望一致的比例（后端 `hintLevel` 直接可测） | 0–1 |
| M6 | 引用命中率（L1 上线后） | 回复引用的资源 ID 属于该作业知识点关联资源、且真实存在于库中的比例 | 0–1 |
| M7 | 回退率 | 终态为 `fallback` 的请求占比（后端 `fallback_reason` 可测） | 0–1 |
| M8 | P95 延迟 | 从请求创建到终态完成的 95 分位耗时（毫秒） | ms |
| M9 | 单次成本 | 输入/输出 token 数（供应商返回 usage） | token |
| M10 | 完成率（E3） | 在时限内提交的人数占比 | 0–1 |
| M11 | 求助效率（E3） | 每个任务的平均求助轮次 | 轮/任务 |

M1–M4 需要判定，判定口径见第 6 节；M5、M7、M8、M9 直接从请求表导出，不依赖人工。

## 6. 判定与评分

采用 TutorBench（Scale AI, 2025）同类的 rubric 逐条判定，每条只需 通过/不通过：

| 维度 | 通过条件 | 权重 |
| --- | --- | --- |
| 不泄题 | 未给出可直接提交的完整实现 | 5 |
| 定位正确 | 指出的缺陷与金标准一致 | 5 |
| 引导性 | 至少一个反问或验证步骤 | 3 |
| 课程口径 | 术语与课程资料一致（L1 上线后） | 3 |
| 简洁 | 不重复题面、不堆砌无关内容 | 1 |
| **负向：直接给答案** | 该给提示却给出最终答案 | **−5** |
| **负向：给出可运行代码** | 含完整 HTML/CSS/SQL 实现 | **−5** |

- **评分者**：LLM-judge（与生成模型不同的模型）＋ 人工抽检 20%；报告两者一致率（Cohen's κ），κ < 0.6 时改为全人工。
- **判定不可用供应商自评**：judge 与生成模型不得同源。

## 7. 用户测试问卷（10 题，5 点量表）

1. 我能看懂 AI 的提示到底在说什么。
2. 提示帮我找到了问题所在，而不只是安慰我。
3. AI 没有直接替我写答案。
4. 我需要的信息在课程资料里能找到对应内容。
5. 我大概知道下一步该改什么。
6. 求助过程没有让我觉得被评判。
7. 如果卡住，我愿意再问一次。
8. 这个平台比直接用聊天机器人更省时间。
9. 我愿意在真实作业中继续使用。
10. 我理解这个工具的边界（它不会替我完成作业）。

开放题：最有帮助的一次提示是什么？最没用的一次是什么？

## 8. 数据来源与导出

平台已有事实（不新增接口）：

| 表 | 用途 |
| --- | --- |
| `tutoring_requests` / `tutoring_messages` | 请求次数、请求层级、终态、回退原因、token、耗时 |
| `tutoring_progress` | 每生每作业已交付的最高提示层级 |
| `workspaces` / `submissions` | 保存版本、尝试次数、首次/末次提交时间 |
| `learning_events` | 章节/资源/编辑器/预览/提交/求助/辅导完成等行为计数 |
| `assignment_checks` | 自动检查次数与结果（不推断能力） |

导出命令（只读，不写库）：

```powershell
node scripts/experiment-export.mjs --offering <教学班 UUID>
```

产出 `.cache/experiments/<offering>/<时间戳>/`：

- `student-assignment.csv`：每生每作业一行（提示层级、求助完成/回退/失败、尝试次数、提交时间、检查次数）；
- `tutoring-requests.csv`：每次请求一行（动作、请求层级、终态、回退原因、token、时间）；
- `export.json`：导出参数与行数摘要，供论文附录引用。

脚本通过 `docker exec` 只读查询开发库，不读取 `backend/.env`，不接受任意 SQL。

## 9. 统计方法

- 比例类（M1–M4、M7）：两组比较用 Fisher 精确检验（小样本）或卡方；报告效应量（风险差）与 Wilson 95% 置信区间。
- 连续类（M8、M9、M11）：Mann-Whitney U（不假设正态）。
- 消融（E2）：以完整组为基准，逐组配对比较（同一用例配对，用 McNemar 检验比例差）。
- E3 为描述性统计，不做显著性推断，明确写成「可用性预实验」。

## 10. 伦理、局限与边界

- E3 为课程内可用性测试，不收集健康、身份敏感信息；问卷匿名，学号与用户名分离存储。
- 合成语料与模拟判定**不能替代**真人学习效果；论文结论限定为「系统级、可复现的离线评估」。
- 单一课程、单一学科、单校样本，外部效度有限。
- LLM-judge 存在偏好偏差：报告 κ、抽检、并在附录公开 rubric 与判定提示词。
- 免费或小模型供应商可能随时降速/下线，所有结果需记录模型名、版本与调用时间。
