# 演示路线（12 分钟）

面向课堂演示与答辩录屏的固定脚本。目标不是"把所有功能走一遍"，而是用一条可信的闭环讲清楚三件事：
**双模式注册 → 受限式 AI 辅导与求助 → 基于学习行为的分析与掌握状态**。

- 适用：`real` 模式（`VITE_API_MODE` 不设或为 `real`）、本机 4173 + 8080 + 3307。
- 不使用 mock 层、不放加速演示、不开 `/debug/session`。
- 每一步都写清"点哪里、期望看到什么、失败怎么办"；`/` 后是 hash 路由，完整地址形如
  `http://127.0.0.1:4173/#/register`。

## 0. 演示前提

| 项 | 要求 |
| --- | --- |
| 环境 | Docker 已启动（MySQL 3307 健康）、后端 8080 `health/ready` 返回 200、前端 4173 已启动 |
| 浏览器 | 固定 `http://127.0.0.1:4173`（不要混用 `localhost`，cookie 与 Origin 都按 127.0.0.1 配置） |
| 账号 | `teacher.demo`、`student.demo`（密码在 `backend/.env`，现场不要打开该文件） |
| 数据 | 见 §1 一次性准备；**当前本地库只有 V16 的个人 Web 课程，没有教学班、作业与提交** |
| 现场禁忌 | 不展示 `.env`、不点「归档教学班」、不演示 AI 的真实回答（外部供应商按合规保持关闭） |

## 1. 演示前一次性准备（约 15 分钟）

只有第一次需要做；数据库重建后要重做。全程用真实界面，和演示时的操作一致。

1. **起环境**：Docker 恢复运行 → `backend/scripts/Start-Local.ps1 -JdkPath 'C:\Program Files\Java\latest\jdk-21'`
   → `cd frontend && npm run dev`。浏览器打开 `/#/login`，用 `teacher.demo` 登录。
2. **建教学班**：`/#/teacher` → 「创建教学班」→ 填班级名称（如「工程实践 · 演示班」）→ 创建 → 进入工作台
   `/#/teacher/offerings/{id}`。
3. **建章节**：工作台「章节与资料」→ 新建章节（标题如「HTML 结构与表单」）→ 发布。
4. **建邀请码**：「邀请码」→ 创建邀请码 → **立刻复制明文**（只显示一次，关闭后无法找回）。
5. **建作业**：「作业管理与批阅」→ 新建作业 → 类型 `web_lab` → 填要求、量规、初始文件（如 `index.html`）→ 发布。
6. **准备两个演示学生**（学校模式）：打开无痕窗口 `/#/register` → 选「学校」→ 角色「学生」→ 填用户名
   `demo.s1`、显示名、密码、粘上一步的邀请码 → 注册成功即入班。重复一次建 `demo.s2`。
7. **制造一条待批阅提交**：用 `demo.s1` 登录 → `/#/student/assignments` → 打开作业 → 「开始作答」→
   `/#/student/workspaces/{id}` 写几行代码 → 保存 → 提交。
8. **让 s2 产生学习行为**：用 `demo.s2` 打开课程章节页停留几秒（产生 `chapter_opened` 事件）。
9. **自检**：`teacher.demo` 工作台统计里「学生 2 / 进行中作业 1」；作业管理里「1 提交 / 1 待批阅」；
   学习分析页有活跃数据且不空白。

> 想省掉准备？可以补一个走产品接口的 `scripts/demo-seed.mjs`（建班、建章、建作业、注册学生、提交一次）。
> 目前**未实现**，属于可选后续工作；本文只保证手动准备路径可用。

## 2. 演示脚本

### S1 开场（30 秒）

- 打开 `/#/login`，一句话定位：「面向 Web 开发课程的学习平台，核心是受限式 AI 辅导与学习行为分析。」
- 讲点：同一入口、两种身份（教师/学生），注册自助。

### S2 个人模式注册（60 秒）

1. 点登录页「自助注册」→ `/#/register`。
2. 第一步填用户名（小写字母数字）、显示名、密码（≥8 位，含大小写与数字）。
3. 选「个人自学」→ 确认。
4. 期望：注册成功直接进入学生首页，**身份不再要求二次登录**。
5. 讲点：注册即建立会话；个人模式自动关联「Web 开发基础（个人学习）」课程，不需要教师开班。

### S3 课程与学习行为（60 秒）

1. 侧栏「我的课程」→ 个人 Web 课程 → 第 1 章「HTML 基础」。
2. 期望：章节正文、资料、知识点可见；右上或底部出现学习进度。
3. 侧栏「学习记录」→ 能看到刚才的章节访问与掌握概览入口。
4. 讲点：章节打开会写学习事件（`chapter_opened`），这是后面分析页的数据来源。

### S4 工作区：作答、预览、AI 求助（3 分钟）

1. 退出，用 `demo.s1` 登录 → 侧栏「我的作业」→ 打开的作业 → 「继续作答」。
2. `/#/student/workspaces/{id}`：顶栏「题目 / 运行 / AI / 提交作业」。
3. 在编辑器里改 `index.html` → 点「运行」→ 右侧输出面板出现隔离预览（iframe srcdoc + CSP + sandbox）。
4. 点「AI」→ 抽屉展开，输入一个问题并发送。
5. 期望与讲法：**外部供应商按合规关闭**，请求会以受限/不可用提示结束；此时强调平台的三条规则：
   提示分层、不直接给答案、可一键升级为教师求助。不要声称"AI 已给出答案"。
6. 点「提交作业」→ 确认提交 → 期望提交记录新增一次，状态变为待批阅。

> 兜底：若 AI 请求报错文案不够友好，直接跳过第 4 步，改点作业详情页的「向教师求助」链路（同样能讲"受限 AI 的升级路径"）。

### S5 教师批阅（2.5 分钟）

1. 用 `teacher.demo` 登录 → `/#/teacher` → 演示班工作台。
2. 讲点：班级统计（学生数、进行中作业数）；分页标签 章节与资料 / 知识点 / 成员 / 邀请码 / 公告 / 学生求助。
3. 点「作业管理与批阅」→ 打开作业 → 「学生提交」→ 找 `demo.s1` 的提交 → 点「批阅」。
4. 在弹出的批阅抽屉里：量表评分 → 知识点评价（可只评部分）→ 「保存草稿」→ 「发布」。
5. 期望：发布后学生收到通知；该评价成为知识点证据，参与掌握状态计算。
6. 讲点：草稿与已发布分离、发布幂等、评价不会覆盖历史证据。

### S6 学生视角的反馈（1 分钟）

1. 切回 `demo.s1`：作业详情 → 评价区可见分数与评语；「消息」出现未读。
2. 讲点：学生看到的是"可行动反馈"，不是只读成绩单。

### S7 学习分析（1.5 分钟）

1. 教师工作台 → 「学习分析」`/#/teacher/offerings/{id}/analytics`。
2. 讲点：14 天活跃卡片与摘要、两张趋势图、四态掌握分布、无障碍明细表。
3. 强调：**共性问题只展示，不映射知识点**；标签来自教师评价与求助，不是模型猜的。

### S8 学生掌握概览（1 分钟）

1. `demo.s1` 侧栏「学习记录」→ 掌握概览：四色图例、分段条、说明文字。
2. 讲点：掌握状态由证据（评价/行为）聚合，教师可下钻到单个学生的学习记录。

### S9 学校模式注册（可选，60 秒）

1. 新无痕窗口 `/#/register` → 「学校」→ 角色「学生」→ 填邀请码（现场从教师端再创建一个）→ 注册。
2. 期望：直接入班，首页出现该班级与作业。
3. 讲点：学校模式=已有班级；个人模式=自助开课，两条路径共用一套会话与权限。

### S10 收尾（30 秒）

- 一句证据：契约 86 操作（13 verified / 69 implemented / 4 planned）、后端 469+259 测试、前端 408 用例、
  注册与学习分析均有真实 MySQL 与浏览器证据；P3 自动检查未实现，不夸大。

## 3. 故障兜底

| 现象 | 处理 |
| --- | --- |
| 页面报「服务不可用」/ 登录 503 | `curl http://127.0.0.1:8080/health/ready`；503 多半是 Docker 被暂停或 MySQL 未起 → 恢复后刷页 |
| 登录后立刻跳回登录页 | 后端重启过导致预登录签名失效 → 刷新页面重新取 CSRF 再登录 |
| 邀请码提示无效 | 邀请码过期或被用尽；回教师端重新生成并用**明文当场**注册 |
| 分析页空白 | 该班还没有学习事件/评价；补一次章节访问或先发布一条评价 |
| AI 面板报错 | 属预期（供应商关闭）；按 S4 兜底改讲求助链路，不要临场改配置 |
| 端口占用 | 前端固定 4173，被占用就关掉旧进程；不要临时换端口（cookie 与 Origin 已按 4173 配置） |

## 4. 演示后恢复

- 演示产生的账号、班级、提交都是真实数据，保留即可；要回到干净状态就重建库：
  `docker exec <db容器> ...` 重建 `learning_platform` → `Start-Local.ps1 -InitializeAccounts` → 按 §1 重新准备。
- 若演示中误点了「归档教学班」，该班立即只读且无恢复入口，只能按上一行重建。
